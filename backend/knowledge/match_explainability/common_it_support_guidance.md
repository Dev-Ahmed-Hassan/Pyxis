# Common IT Support Guidance

This document supports IT support, system administration, helpdesk, and
technical support roles.

## IT Support Role Signals

chunk_type: career
field: it_support
role: IT Support Intern
skills: troubleshooting, Windows, Linux, networking, documentation
purpose: role-fit

IT support internships usually value troubleshooting, customer communication,
ticket documentation, basic Windows and Linux administration, networking
fundamentals, hardware/software setup, and escalation judgment.

Strong evidence names:

```text
issue diagnosed
steps taken
tool or command used
root cause
resolution
documentation or escalation
```

## System Administration Role Signals

chunk_type: career
field: it_support
role: System Administration Intern
skills: Linux, Windows, scripting, users, permissions, backups
purpose: role-fit

System administration roles value user management, permissions, services,
logs, backups, patching, scripting, and monitoring. Cybersecurity students can
use home labs to demonstrate sysadmin readiness.

Partial evidence includes general Linux familiarity without administration
tasks.

## Troubleshooting Evidence Standards

chunk_type: domain
field: it_support
role: IT Support Intern
skills: troubleshooting, documentation, communication
purpose: evidence-standard

Direct troubleshooting evidence explains the problem, diagnostic steps, tools
used, result, and how the fix was communicated. Merely listing "problem
solving" is weak evidence.

Good troubleshooting bullets include:

```text
diagnosed network connectivity issue
used ping, traceroute, ipconfig, netstat, journalctl, or logs
documented root cause and resolution
```

## Helpdesk Lab Project

chunk_type: project
field: it_support
role: IT Support Intern
skills: troubleshooting, Windows, Linux, ticket documentation
purpose: missing-skill-project

Use this project when the student lacks IT support evidence.

Project:

```text
Create a home lab checklist with five common issues such as DNS failure, wrong
IP configuration, locked account simulation, service not running, and disk
space warning. Document symptoms, commands, diagnosis, and fix.
```

Resume bullet:

```text
Built an IT troubleshooting lab documenting diagnosis and resolution steps for
DNS, IP configuration, service, account, and disk-space issues.
```

## IT Support Interview Guidance

chunk_type: interview
field: it_support
role: IT Support Intern
skills: troubleshooting, communication, escalation
purpose: interview-prep

Common IT support interview questions:

```text
A user cannot access the internet. What do you check first?
How do you explain a technical issue to a non-technical user?
When would you escalate a ticket?
What is DNS?
How do you document a resolved issue?
```

Strong answers should be step-by-step, calm, and user-focused.
