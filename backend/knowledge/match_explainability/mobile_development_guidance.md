# Mobile Development Guidance

This document supports Android, iOS, and cross-platform mobile development
roles.

## Mobile Developer Role Signals

chunk_type: career
field: mobile_development
role: Mobile Developer Intern
skills: Android, iOS, Flutter, React Native, API integration, local storage
purpose: role-fit

Mobile internships usually value evidence of building screens, navigation,
API integration, local storage, forms, authentication, and responsive mobile UI.
Strong evidence includes a runnable app, screenshots, demo video, state
management, and clear setup instructions.

Strong evidence names:

```text
platform
screens built
API integration
local storage
state management
testing or release notes
```

## Android Role Signals

chunk_type: career
field: mobile_development
role: Android Developer Intern
skills: Kotlin, Java, Android Studio, Jetpack, REST API
purpose: role-fit

Android roles value Kotlin or Java, Android Studio, activities or fragments,
Jetpack components, API calls, local persistence, and UI lifecycle awareness.
If Java is a missing skill in another match, an Android project can also create
Java evidence.

## Mobile App Project Suggestion

chunk_type: project
field: mobile_development
role: Mobile Developer Intern
skills: mobile UI, API integration, local storage
purpose: missing-skill-project

Use this project when the student lacks mobile evidence.

Project:

```text
Build a simple habit tracker, expense tracker, or study planner mobile app
with multiple screens, local storage, form validation, and optional API sync.
```

Resume bullet:

```text
Built a mobile habit-tracking app with multi-screen navigation, local storage,
form validation, and reusable UI components.
```

## Mobile Interview Guidance

chunk_type: interview
field: mobile_development
role: Mobile Developer Intern
skills: navigation, state, API integration, storage
purpose: interview-prep

Common mobile interview questions:

```text
How does your app manage state between screens?
How do you handle API failures?
What data should be stored locally?
How would you improve performance on a low-end device?
How do you test a mobile app?
```

Strong answers should mention user experience, lifecycle, data persistence,
and error handling.
