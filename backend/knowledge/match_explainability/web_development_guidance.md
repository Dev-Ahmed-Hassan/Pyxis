# Web Development Guidance

This document supports frontend, backend, and full-stack web development
matches, career suggestions, project recommendations, and interviews.

## Frontend Developer Role Signals

chunk_type: career
field: web_development
role: Frontend Developer Intern
skills: HTML, CSS, JavaScript, React, responsive design, UI state
purpose: role-fit

Frontend internships usually value evidence of responsive layouts, component
design, state management, API integration, accessibility basics, form handling,
and user experience. Strong evidence includes deployed web apps, clean UI,
reusable components, loading and error states, and clear README screenshots.

Strong evidence names:

```text
framework or library
component structure
API integration
state management
responsive behavior
accessibility or validation
```

## Backend Web Developer Role Signals

chunk_type: career
field: web_development
role: Backend Web Developer Intern
skills: REST API, database, authentication, validation, server-side logic
purpose: role-fit

Backend web roles value APIs, database persistence, authentication,
authorization, input validation, error handling, logging, security basics, and
clear API documentation.

Partial evidence includes frontend-only work or static websites without
server-side behavior.

## Full Stack Developer Role Signals

chunk_type: career
field: web_development
role: Full Stack Developer Intern
skills: frontend, backend, database, API integration, deployment
purpose: role-fit

Full-stack evidence is strongest when the student connects frontend screens to
backend APIs and persistent storage. A good full-stack project explains both
client and server responsibilities.

Good evidence includes:

```text
frontend forms
API calls
backend endpoints
database schema
authentication flow
deployment or local setup
```

## Web Development Interview Guidance

chunk_type: interview
field: web_development
role: Frontend Developer Intern
skills: JavaScript, UI state, API integration
purpose: interview-prep

Common web development interview questions:

```text
How does your frontend communicate with the backend?
How do you handle loading and error states?
What is the difference between client-side and server-side validation?
How do you protect routes that require login?
How would you make this page responsive and accessible?
```

Strong answers should connect user experience, code structure, and data flow.
