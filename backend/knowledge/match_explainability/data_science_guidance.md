# Data Science Guidance

This document supports data science career suggestions, match explanations,
project recommendations, and interview preparation.

## Data Analyst Role Signals

chunk_type: career
field: data_science
role: Data Analyst Intern
skills: SQL, Excel, Python, pandas, visualization, reporting
purpose: role-fit

Data analyst internships usually value evidence of querying data, cleaning
data, building dashboards, creating reports, and explaining business insights.
Strong evidence includes SQL queries, Excel analysis, pandas notebooks,
Power BI or Tableau dashboards, and written insight summaries.

Strong resume evidence names:

```text
dataset
question answered
SQL query or analysis method
visualization
business insight
recommendation
```

## Data Scientist Role Signals

chunk_type: career
field: data_science
role: Data Scientist Intern
skills: statistics, Python, pandas, machine learning, feature engineering
purpose: role-fit

Data scientist roles require stronger evidence of statistics, feature
engineering, modeling, experiment design, and communicating uncertainty. A
student does not need production ML experience, but should show careful
analysis and evaluation.

Partial evidence includes general Python programming or dashboards without
statistical analysis or modeling.

## SQL Analytics Evidence Standards

chunk_type: domain
field: data_science
role: Data Analyst Intern
skills: SQL, joins, aggregation, filtering, reporting
purpose: evidence-standard

Direct SQL analytics evidence includes joins, aggregations, filtering,
window functions, subqueries, schema understanding, and converting results
into a report or dashboard.

Partial evidence includes database usage in an app without analytical queries.
Explain it as database development evidence, not necessarily analytics
evidence.

## Dashboard Project Suggestion

chunk_type: project
field: data_science
role: Data Analyst Intern
skills: SQL, dashboard, visualization, business reporting
purpose: missing-skill-project

Use this project when the student lacks analytics or dashboard evidence.

Project:

```text
Analyze a public sales, finance, or operations dataset. Write SQL queries,
clean data in Python or Excel, create a dashboard, and summarize three
business insights.
```

Resume bullet:

```text
Built an analytics dashboard from a public dataset using SQL and Python,
summarizing trends, key metrics, and business recommendations.
```

## Data Science Interview Guidance

chunk_type: interview
field: data_science
role: Data Analyst Intern
skills: SQL, visualization, metrics, communication
purpose: interview-prep

Common data interview questions:

```text
Explain a dataset you analyzed and what insight you found.
How would you handle missing values?
What is the difference between WHERE and HAVING?
How would you explain a dashboard to a non-technical stakeholder?
What metric would you choose for this business problem?
```

Strong answers should connect technical analysis to a clear decision or
business question.
