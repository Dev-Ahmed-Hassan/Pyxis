# Cyber Project Suggestions

This document maps common cybersecurity gaps to practical projects that can
create truthful resume and interview evidence.

## SIEM Mini SOC Lab

chunk_type: project
field: cybersecurity
role: SOC Analyst Intern
skills: SIEM, log analysis, alert triage, incident response
purpose: missing-skill-project

Use this project when the student lacks SIEM, alert triage, or log analysis
evidence.

Project:

```text
Set up Wazuh or Elastic, ingest Linux authentication logs, trigger an alert for
repeated failed SSH logins, triage the alert, and write an incident note.
```

Resume bullet:

```text
Built a mini SOC lab with Wazuh to ingest authentication logs, detect repeated
failed SSH attempts, triage alerts, and document incident response steps.
```

## Web Pentest Report

chunk_type: project
field: cybersecurity
role: Penetration Testing Intern
skills: OWASP Top 10, Burp Suite, vulnerability reporting
purpose: missing-skill-project

Use this project when the student lacks direct web application security or
professional reporting evidence.

Project:

```text
Test OWASP Juice Shop or DVWA, identify three vulnerabilities, collect proof of
concept evidence, explain impact, and write remediation advice.
```

Resume bullet:

```text
Created a web application penetration testing report for an OWASP lab,
documenting vulnerability evidence, impact, and remediation guidance.
```

## PowerShell Security Script

chunk_type: project
field: cybersecurity
role: SOC Analyst Intern
skills: PowerShell, Windows security, log analysis
purpose: missing-skill-project

Use this project when PowerShell is a missing or preferred skill.

Project:

```text
Write a PowerShell script that collects recent Windows security events,
summarizes failed logons, and exports suspicious entries to a CSV report.
```

Resume bullet:

```text
Developed a PowerShell security script to extract Windows event logs, summarize
failed logon activity, and generate CSV triage reports.
```

## IDS Rule Lab

chunk_type: project
field: cybersecurity
role: SOC Analyst Intern
skills: IDS, Snort, Suricata, network traffic analysis
purpose: missing-skill-project

Use this project when the student has threat detection or packet analysis
evidence but lacks direct IDS tool evidence.

Project:

```text
Set up Snort or Suricata in a lab, replay sample traffic, write or enable a
simple detection rule, and document the generated alert.
```

Resume bullet:

```text
Configured a Snort/Suricata IDS lab to inspect network traffic, trigger alerts
from detection rules, and document alert triage outcomes.
```
