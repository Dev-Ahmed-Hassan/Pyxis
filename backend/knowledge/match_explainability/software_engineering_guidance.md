# Software Engineering Guidance

This document supports software engineering match explanations, career
suggestions, project recommendations, and interview preparation.

## Software Engineering Intern Role Signals

chunk_type: career
field: software_engineering
role: Software Engineering Intern
skills: data structures, algorithms, OOP, Git, testing, APIs
purpose: role-fit

Software engineering internships usually value evidence of programming
fundamentals, object-oriented design, data structures, algorithms, debugging,
version control, testing, and building complete applications. Strong student
evidence includes projects with clear features, readable code, tests, API
design, and explanation of design tradeoffs.

Strong evidence names:

```text
language
architecture
data structure or algorithm used
testing approach
user-facing feature
tradeoff or limitation
```

## Backend Engineering Role Signals

chunk_type: career
field: software_engineering
role: Backend Engineering Intern
skills: REST API, database, authentication, authorization, testing
purpose: role-fit

Backend roles value APIs, database modeling, authentication, authorization,
validation, error handling, testing, and deployment basics. Strong evidence
includes FastAPI, Django, Flask, Express, Spring Boot, PostgreSQL, MongoDB,
JWT, SQLAlchemy, REST design, and API documentation.

Partial evidence includes building a UI-only app or using a database without
clear backend logic.

## Core CS Evidence Standards

chunk_type: domain
field: software_engineering
role: Software Engineering Intern
skills: OOP, DSA, debugging, testing
purpose: evidence-standard

Direct software engineering evidence shows the student built and reasoned
about code. Stronger evidence includes tests, modular structure, error
handling, input validation, and explanation of design choices.

Listing a programming language alone is weaker than showing it inside a
project with features and implementation details.

## Software Engineering Interview Guidance

chunk_type: interview
field: software_engineering
role: Software Engineering Intern
skills: DSA, OOP, debugging, system design basics
purpose: interview-prep

Common software engineering interview questions:

```text
Explain a project architecture you designed.
What data structure did you use and why?
How did you debug a difficult issue?
How do you test your code?
Explain the difference between authentication and authorization.
How would you improve this project if given more time?
```

Strong answers should explain tradeoffs, not just list tools.
